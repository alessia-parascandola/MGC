# 📌 Fuga dal Cassero

"Fuga dal Cassero" è un gioco di ruolo fantasy da tavolo convertito in applicazione desktop Java con interfaccia 
grafica JavaFX. Il programma consente di gestire l'esplorazione di carte capitolo, combattimenti interattivi 
contro mostri e boss, e la gestione dell'inventario tramite drag-and-drop visivo e finestre di dialogo dedicate.

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone https://github.com/alessia-parascandola/MGC
cd MGC
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```

## 🤖 Uso di strumenti di AI

Durante lo sviluppo del progetto sono stati utilizzati Google Gemini come supporto alla progettazione e alla programmazione iniziale e OpenAI Codex per la successiva revisione, correzione e ottimizzazione del codice e dell'interfaccia grafica.

Sono stati inoltre utilizzati strumenti di AI generativa per la realizzazione di alcune risorse grafiche.

Il progetto è stato sviluppato inizialmente dallo studente e successivamente migliorato con il supporto dell'intelligenza artificiale.

📌 Per una descrizione più dettagliata dell’uso dell’AI, utilizzare la **Wiki del repository**.
