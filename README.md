# 📌 Fuga dal Cassero

"Fuga dal Cassero" è un gioco di ruolo fantasy da tavolo convertito in applicazione desktop Java con interfaccia 
grafica JavaFX. Il programma consente di gestire l'esplorazione di carte capitolo, combattimenti interattivi 
contro mostri e boss, e la gestione dell'inventario tramite drag-and-drop visivo e finestre di dialogo dedicate.

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone https://github.com/alessia-parascandola/MGC
cd MGC
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```

## 🤖 Uso di strumenti di AI

Nel corso dello sviluppo del progetto, l'Intelligenza Artificiale è stata utilizzata come assistente e aiutante 
virtuale per l'intera stesura del codice, la risoluzione di bug e la strutturazione dell'interfaccia grafica. 
Inoltre, sono stati impiegati strumenti di IA generativa per la creazione delle risorse grafiche 
(immagini e illustrazioni) utilizzate nel gioco. 

Tutto il codice prodotto è stato attentamente revisionato, testato e integrato personalmente per garantire 
la piena comprensione e il rispetto dei requisiti. Per una descrizione dettagliata, consultare la Wiki del repository.
